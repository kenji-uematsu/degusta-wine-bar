# ワインバー Web サイト 初期モック仕様書

> このドキュメントは、店主へのヒアリング前に提示するための初期モック用の仮仕様です。
> 未確定事項はそのまま空欄または仮値として扱い、最終的な正式な情報ではありません。

## 1. 目的

- 店主へのヒアリング前に、サイトの方向性と要素構成を共有する。
- 後から本番サイトへ発展しやすいよう、構造とコンテンツの分離を意識したモックを作る。
- 1ページ構成の提案として、必要最低限の内容と見出し構成を固める。

## 2. 前提と扱い

- 店名、住所、営業時間、席数、予約方法は未確定のため、仮情報として扱う。
- 画像、ロゴ、ブランド名、価格帯は後ほど確定する前提とする。
- このモックは「情報確認の素材」であり、事実確認済みの情報ではない。

## 3. 想定するサイト構成

### 3.1 ヘッダー
- ロゴ: 予定（仮）
- ナビゲーション: Concept / Wines / Story / Visit / Reserve
- CTA: 予約の案内

### 3.2 ヒーロー
- 見出し: 「ワインと時間を愉しむ空間」
- サブテキスト: 「地元の良い酒と、心地よい時間をつくるワインバー」
- バナー画像: 仮のインテリア写真または食器・ワインのイメージ

### 3.3 概要
- 店のコンセプト説明
- 立ち寄りやすさ、落ち着いた雰囲気、こだわりのワイン選び

### 3.4 ワインセレクション
- 注目ワインの簡易紹介
- 価格や産地の表示は未定
- 1〜3本程度の仮カードを配置

### 3.5 店の物語
- 開店の想い
- お客様との距離感
- こだわりの食材・酒・空間

### 3.6 訪問情報
- 住所: [仮: 東京都〇〇区〇〇]
- 営業時間: [仮: 18:00〜23:30]
- 定休日: [仮: 月曜]
- 予約: [仮: Instagram / 電話 / Web予約]

### 3.7 フッター
- 店名（仮）
- SNSリンク（仮）
- コピーライト表記

## 4. 未確定事項

- 実際の店名
- 物件情報と所在地
- 営業時間と定休日
- 価格帯や席数
- 予約方法と予約ツール
- ロゴ、配色、フォント、デザインイメージ
- 画像の著作権や使用許諾

## 5. 実装メモ

- 1ページサイトとして構成する
- セクションごとに独立したコンポーネントとして分ける
- 画像やテキストは後で差し替えやすいように管理する
- Cloudflare Pages 向けの静的サイトとして推奨構成を維持する

## 6. 次の確認事項

- 店名の正式な表記
- 店舗の位置情報とアクセス
- 想定されるターゲット層
- 予約の実運用方法
- ヒアリング後に反映するブランドトーン
